# PCY Parent App 移动端界面改版 · 三方向设计说明书

## 0 · 项目与背景
- **产品名称**：PCY Tech 校车家长端移动应用 (Parent Bus Tracking Mobile App)
- **核心受众**：中小学生家长（关注早晚校车到站时间、实时位置、上下车刷卡安全确认、请假报备与紧急沟通）
- **典型场景**：
  1. 早晨 7:30 慌乱准备出门，家长单手看手机：“校车离我家还有几分钟？到哪个路口了？”
  2. 上午 8:15 家长在公司抽空确认：“孩子上车刷卡了吗？是否已准时进入校园？”
  3. 突发状况：“孩子今天发烧请假，不用派车接”，一键极速报备。
  4. 遇到大雪/暴雨堵车延误，急需联系随车老师或调度中心 Hotline。
- **改版核心诉求**：面向手机用户全面优化（手指单手操作热区、直观大字号 ETA、安全安心感知、多子女顺畅切换）。

## 4a · 六大候选方案 (6 Candidates)

1. **#01 最佳设计师 · Cultured Code (Things 3 式 Native Polish)**
   - 借的：极简白底、32px 紧字距标题、极克制的强调蓝与琥珀黄、缩进发丝线、悬浮轻量卡片。
   - 主角素材：巨幅 3 分钟到站倒计时读数、纯净轻质感地图。
   - 骨架：全屏轻地图 + 底部手势轻浮卡片。
   - 胆量：整页完全不使用花哨渐变，仅靠排印节奏建立绝对的官方可靠感。

2. **#02 最佳设计师 · Jony Ive / Apple iOS 26 Liquid Glass**
   - 借的：半透明磨砂折射面板、悬浮灵动胶囊导航、大圆角气泡。
   - 主角素材：全景环境色渲染、漂浮校车指示物。
   - 骨架：全屏地图衬底 + 四角悬浮玻璃小组件。

3. **#03 现实参照 · Citymapper / Uber Transit 实时动态态势流**
   - 借的：动态站点步进时间轴（Live Transit Stepper）、灵动岛实时到站卡（Live Activity）、红黄绿路况感知。
   - 主角素材：校车动态脉冲点、路线站点打卡轴。
   - 骨架：两段式雷达布局，上半部为动态路线雷达，下半部为站点逐站推演。

4. **#04 现实参照 · Apple Find My (查找) + Life360 家庭安全圈**
   - 借的：孩子头像为视觉圆心、地理安全围栏（Geofence Radius）、到达/离开学校即时提示。
   - 主角素材：孩子头像脉冲光环、电子围栏半透明范围。
   - 骨架：地图置底，底部紧凑抽屉拉起多孩安全清单。

5. **#05 秒数轮盘 · Gentler Streak 亲和暖色家庭便当盒 (Family Bento)**
   - 借的：深海蓝底板（#18213A）、28px 大圆角 Bento Grid 便当盒、低饱和粉彩状态胶囊（薄荷绿安全、蜜桃黄行程中）、温暖不焦虑的情绪文案。
   - 主角素材：多子女便当盒卡片、平滑圆头通勤轨迹。
   - 骨架：首屏多孩卡片并列便当盒，点击单卡无缝展开伴随视窗。

6. **#06 秒数轮盘 · 节气色谱 / 东方温润纸质守护**
   - 借的：温润纸色、墨黑细线、朱砂印章打卡标记。
   - 主角素材：温润矢量绘本风格校车图标。
   - 骨架：竖向竹简式行程单。

## 4d · 挑出的三大完整呈现方向 (The 3 Full Directions)

| 方案 | 方向定义 | 核心视觉与交互DNA | 解决家长的什么痛点 |
| :--- | :--- | :--- | :--- |
| **方向 A** | **Native Polish (极简原生·极致信任)** | 纯净白底、大字号清晰读数、Things 3 级别严谨留白、单手拇指交互抽屉 | 早上时间紧迫，扫一眼 1 秒内获知到站时间，毫无多余认知负担 |
| **方向 B** | **Transit Radar (实时态势·动态步进)** | Citymapper/Uber 风格动态地图、站点时间轴胶囊 (Timeline Stepper)、Live Activity 灵动岛联动 | 实时掌控校车到底开到了哪个路口，清楚知道前面还有几站 |
| **方向 C** | **Family Bento (暖心守护·便当盒架构)** | 28px 圆角便当盒卡片、深海蓝+柔和粉彩、多子女一键平铺切换、减焦虑安抚文案 | 拥有两个及以上孩子的家庭，一屏同时看清所有孩子的通勤状态，视觉温馨有安全感 |
