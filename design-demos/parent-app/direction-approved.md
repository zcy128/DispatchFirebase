# Direction Approved · PCY Parent Mobile App

- **选择时间**：2026-10-30 09:10:21
- **用户原话**：「方案 C」
- **选定方向**：方向 C · Gentler Streak 暖心守护 (Family Bento 便当盒架构)
- **核心设计风格与交互特征**：
  1. **色彩与材质**：深海蓝底（`#0B101D` / `#121929`），搭配 28px 圆角 Bento Grid 便当盒卡片，低饱和度柔和状态粉彩（薄荷绿 `#9BE0CC` 安全在车、蜜桃暖黄 `#FCD34D` 行程中与到站倒计时、薰衣草紫 `#BAC3FA`、珊瑚红紧急）。
  2. **情绪安抚文案**：以减缓家长晨晚接送焦虑为核心（“Ethan 已在车上，车速平稳，正在安全返程”）。
  3. **便当盒架构**：多子女一键并列状态总览与极速切换（Ethan / Emma），2x2 关键数据矩阵（到站时间、上下车状态、随车司机认证、500 米安全围栏）。
  4. **1-Tap 快捷功能**：极速请假报备、一键连通调度与紧急热线、SMS 查询指令。
